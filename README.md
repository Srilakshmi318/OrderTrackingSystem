📦 Order Tracking System
📌 Problem Statement

Develop an Order Tracking System that records customer orders, updates order status (Pending, Shipped, Delivered), and displays order details along with the current status using appropriate classes, constructors, and methods.

🚀 Project Overview

This project is a simple web-based Order Tracking System built using HTML, CSS, and JavaScript.
It helps users manage orders by performing basic operations like adding, updating, searching, and deleting orders. The application uses localStorage to store data in the browser.

✨ Features
➕ Add new customer orders
🔄 Update order status (Pending / Shipped / Delivered)
🔍 Search orders by Order ID
🗑 Delete orders
💾 Data persistence using browser localStorage
🎨 Simple and user-friendly interface
🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
Browser localStorage

▶️ How to Run the Project
Clone or download the repository
Open the folder in VS Code
Double-click index.html
The project will open in your browser
Start managing orders
⚙️ How It Works
Orders are stored as objects in a JavaScript array
Each order contains:
Order ID
Customer Name
Product Name
Status
Data is saved in localStorage so it remains after refresh
Functions handle:
Add Order
Update Status
Search Order
Delete Order
